# 微光论坛 SimpleForum

微光论坛是一款面向中文社区的 Android 移动端论坛应用，为用户提供内容发布、话题讨论与社区互动的完整服务。

应用以板块为组织单位，用户可以在不同板块下浏览帖子、参与讨论、发布内容，并通过点赞、评论等方式与他人互动。界面遵循 Material Design 设计规范，交互简洁直接，适合日常社区交流场景。

> 当前版本为 **1.0.0**，已覆盖核心社区功能。后续版本将逐步上线消息通知、内容收藏、图文发布等能力，具体见[版本规划](#版本规划)。

## 功能特性

### 账号体系

| 功能 | 说明 |
|---|---|
| 注册 | 支持用户名 / 昵称 / 邮箱 / 密码注册，内置格式校验与重复校验 |
| 登录 | 支持用户名或邮箱登录 |
| 记住密码 | 可选记住登录凭证，下次打开自动填充 |
| 密码可见切换 | 输入过程中可切换明文 / 密文显示 |
| 登录态保持 | 应用重启后自动恢复登录状态 |
| 退出登录 | 一键退出，清除本地登录凭证 |

### 内容浏览

- **帖子列表**：首页按发布时间倒序展示，置顶内容优先显示
- **板块筛选**：支持「全部 / 综合讨论 / 技术交流 / 生活日常 / 求助问答 / 资源分享」六大板块
- **下拉刷新**：随时获取最新内容
- **快捷点赞**：列表页可直接点赞，无需进入详情
- **内容搜索**：支持标题与正文模糊匹配，自动保存搜索历史
- **帖子详情**：展示完整正文、浏览量、点赞数与评论列表

### 内容创作

- **发布帖子**：选择板块、填写标题与正文，实时字数统计
- **编辑保护**：内容未保存时退出会有二次确认，避免误操作丢失
- **发布评论**：支持按楼层组织讨论
- **定向回复**：可针对特定用户回复
- **内容管理**：支持删除自己发布的帖子，评论随之级联清理

### 个人中心

- **个人主页**：展示头像、昵称、个性签名、用户等级
- **数据统计**：发帖数、回复数、经验值一目了然
- **内容管理**：集中查看「我的帖子」与「我的回复」
- **他人主页**：从帖子或评论头像可进入任意用户主页
- **设置中心**：支持修改昵称与签名、清除本地数据、查看版本信息

### 界面与交互

- 启动页自动判断登录状态，智能跳转
- 底部四标签导航：首页 / 板块 / 消息 / 我的
- 完善的空状态与加载态提示
- 全局统一的刷新反馈与消息提示

## 技术栈

| 分类 | 选型 |
|---|---|
| 开发语言 | Java 8 |
| 最低支持版本 | Android 7.0（API 24） |
| 目标编译版本 | API 34 |
| 构建工具 | Gradle 8.2 + Android Gradle Plugin 8.1.2 |
| 本地数据存储 | Room 2.5.2 |
| 图片加载 | Glide 4.15.1 |
| UI 组件 | Material Components 1.9.0、RecyclerView、SwipeRefreshLayout、ViewPager2 |
| 数据存储 | Room（本地持久化）+ SharedPreferences（登录态） |

**关于技术选型**

应用采用 Android 原生技术栈构建，未引入 Compose、MVVM 框架或第三方网络库，目的是保持工程结构清晰、依赖精简，降低安装包体积与维护成本。数据层采用 Repository 模式统一收口：

```
Activity / Fragment  →  Repository  →  Dao
```

页面层只与 Repository 交互，不直接操作数据库；异步任务通过 `ExecutorService` 调度，主线程更新通过 `Handler` 派发，保证界面操作流畅不阻塞。

## 项目结构

```
app/src/main/java/com/linzp/forum/
├── ForumApplication.java          # 应用入口，初始化本地数据
├── base/
│   └── BaseActivity.java          # 页面跳转与返回键统一处理
├── data/
│   ├── db/                        # Room：数据访问对象 + 数据库单例
│   ├── entity/                    # 数据实体：Topic / Reply / User
│   ├── model/                     # 业务模型：板块、统计信息
│   ├── prefs/                     # 登录态管理
│   └── repository/                # 数据统一入口 + 演示数据
├── ui/
│   ├── SplashActivity.java        # 启动页
│   ├── MyContentActivity.java     # 我的内容
│   ├── adapter/                   # 列表适配器
│   ├── login/  register/          # 登录注册模块
│   ├── main/                      # 主界面与四个标签页
│   ├── topic/                     # 帖子详情
│   ├── post/                      # 发布与搜索
│   └── profile/                   # 个人主页与设置
└── util/                          # 通用工具：校验、时间格式化、提示封装
```

## 安装与运行

### 1. 克隆项目

```bash
git clone https://github.com/escapennn/SimpleForum.git
cd SimpleForum
```

### 2. 配置 SDK 路径

在项目根目录创建 `local.properties`（可直接复制 `local.properties.example` 后修改）：

```properties
sdk.dir=C\:\\Users\\你的用户名\\AppData\\Local\\Android\\Sdk
```

> Windows 环境下路径中的冒号与反斜杠需要转义。

### 3. 打开并构建

使用 Android Studio 打开项目，等待 Gradle Sync 完成。

### 4. 运行

连接真机或启动模拟器，点击 Run 即可安装运行。

## 设计说明

**1. 板块数据采用静态配置**

当前板块列表以静态常量定义。板块属于低频变更的业务数据，静态配置可减少一次数据库查询与网络请求。未来如需支持后台动态配置，只需将该常量替换为数据表即可。

**2. 主界面采用 Fragment 保活策略**

底部标签切换使用 `hide()` + `show()` 而非 `replace()`，避免每次切换都重建页面、丢失列表滚动位置，带来更连贯的浏览体验。

**3. 密码采用哈希存储**

用户密码经 MD5 哈希后存储，避免明文落库。生产部署时建议替换为 bcrypt 或 Argon2 等带盐慢哈希算法，以进一步提升安全性。

**4. 数据库版本升级策略**

开发阶段表结构迭代频繁，当前采用 `fallbackToDestructiveMigration` 策略。正式发布前会切换为完整的 Migration 方案，确保用户升级时数据不丢失。
